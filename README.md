# 🏧 ATM System Using Python

A simple, beginner-friendly ATM simulation project developed using Python as part of my learning journey as a **Developer Student Intern at EcoQuantum Solution**.

## 📌 About the Project
This project simulates basic ATM operations through a simple, menu-driven Python program. It helps demonstrate fundamental programming concepts and logical thinking.

## ✨ Features
- 💰 Check account balance
- 💵 Withdraw money
- 💳 Deposit money

## 🛠️ Technologies Used
- **Language:** Python
- **Concepts:** Variables, conditional statements, loops, and user input

## ▶️ How to Run
1. Install Python on your computer.
2. Download or clone this repository.
3. Open the project in your code editor.
4. Run the Python file:

```bash
python atm.py
```
